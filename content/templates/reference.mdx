## 1. Cấu hình chuẩn sẵn sàng sử dụng

```dockerfile title="Dockerfile"
FROM node:22-alpine AS runner
WORKDIR /app
ENV NODE_ENV=production
USER node
EXPOSE 3000
CMD ["node", "server.js"]
```

<Callout type="warning" title="Ràng buộc bảo mật bắt buộc">
  Tuyệt đối không đóng gói tệp `.env` chứa khóa bí mật vào bên trong lớp Docker Image và luôn chạy container bằng tài khoản non-root.
</Callout>

## 2. Lệnh kiểm tra & Chẩn đoán nhanh

```bash title="verify.sh"
docker build -t app-web:latest .
docker images app-web:latest
```
